# Blooming Deserts — project website

Static website for GitHub Pages, built with HTML, CSS, and vanilla JavaScript.

## Preview locally
Open `index.html` in a browser. Google Fonts are loaded from the web; the site itself and image assets are local.

## Publish with GitHub Pages
1. Create a GitHub repository (for example, `blooming-deserts`).
2. Upload the contents of this folder to the repository root (not the ZIP file itself).
3. In **Settings → Pages**, choose **Deploy from a branch**, select `main` and `/ (root)`, then save.
4. GitHub Pages will publish the site at the repository's Pages address.

## Structure
- `index.html` — page content and navigation
- `style.css` — responsive visual design
- `script.js` — mobile navigation
- `assets/` — visual material rendered from the two project PDFs

The safeguarding section is a public overview, not an operational protocol. Check image permissions and institutional approval before public release.
